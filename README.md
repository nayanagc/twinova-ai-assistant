## 📌 Overview

Twinova AI is an intelligent productivity assistant designed to simplify task management, improve focus, and support personal growth. By combining AI-powered planning, behavioral insights, and personalized recommendations, Twinova AI helps users work smarter and achieve their goals more efficiently.

Unlike traditional productivity tools, Twinova AI adapts to user behavior and provides context-aware guidance, making productivity more personalized and effective.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/yourusername/twinova-ai.git
```

### Navigate into the project

```bash
cd twinova-ai
```

### Install dependencies

```bash
npm install
```

### Create Environment Variables

Create a `.env` file and add:

```env
SUPABASE_URL=
SUPABASE_PUBLISHABLE_KEY=

VITE_SUPABASE_URL=
VITE_SUPABASE_PUBLISHABLE_KEY=

OPENAI_API_KEY=

GNANI_API_KEY=
```

### Run the project

```bash
npm run dev
```
